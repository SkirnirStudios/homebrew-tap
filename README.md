# Skirnir Studios Homebrew tap

Homebrew casks for apps by [Skirnir Studios](https://www.skirnirstudios.com).

## Undertone

Per-app volume control in your Mac's menu bar.

```bash
brew install --cask skirnirstudios/tap/undertone
```

Undertone updates itself, so `brew upgrade` leaves it alone. To remove it:

```bash
brew uninstall --cask undertone
```

More about Undertone: [github.com/SkirnirStudios/Undertone](https://github.com/SkirnirStudios/Undertone)
